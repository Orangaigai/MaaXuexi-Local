# 故障排查

| 现象 | 检查与处理 |
| --- | --- |
| 找不到 Python | 安装 Python 3.12 x64；或安装时指定 `-PythonPath` |
| 原生库无法加载、启动闪退 | 检查 Windows x64、VC++ x64 运行库及完整依赖；不要从别的电脑复制 `.venv` |
| MuMu 已启动但没有执行 | 启动器只准备环境；首次手动运行需在网页点击一次执行。核对 `emulator.json` 路径和实例 |
| 未识别到首页或题目 | 检查是否登录、首次弹窗、应用版本及 720×1280 截图尺寸；保存必要的去身份化诊断再提 Issue |
| 端口 8000 占用 | 后台有进程记录时重复启动会复用；否则先确定占用程序，不要直接结束陌生进程。工具只停止自身记录的进程 |
| 浏览器没有自动打开 | 手动访问 <http://127.0.0.1:8000/>；检查 `logs/launcher-*.log` |
| 访问验证 | 在 MuMu 本人完成；程序等待画面恢复。不要重复执行、重开任务或用自动化解验证 |
| 网络开小差、匹配超时 | 不足以单凭提示断定 VPN 或风控原因。查看实际先后过程；超时验证可能已失效。工具保留未完成结果，不保证再次请求成功 |
| DeepSeek 连接失败 | 在本地配置页核对官网密钥、账户余额、接口状态与图片请求权限；不要在 Issue 粘贴密钥 |
| 今日任务没自动开始 | 检查计划任务、Windows 时区、登录状态、休眠、电源及网络。仅联网不够 |
| 没有拿满分 | 查看逐项报告；平台规则、内容计分、模型错误、验证和网络都可能影响结果。不要把离线测试通过当成线上保证 |

离线回归：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py" -q
```

安装检查（不启动任务、不修改计划任务）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-MaaXuexi.ps1 -CheckOnly
```

已有环境的完整自检 `自检MaaXuexi.cmd` 还会检查设备连接、定时清单所需文件和本地后台状态，因此未配置密钥或未启动后台时可以失败。它不会替你完成访问验证。
